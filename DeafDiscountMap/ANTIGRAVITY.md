# プロジェクト憲法 (ANTIGRAVITY.md)

## 1. プロジェクト概要
聴覚障害者割引が使用できるレジャー施設、駐車場、公共交通などの情報を集約し、広く一般に公開・検索できるプラットフォームの開発。

## 2. ターゲット
- 広く一般のユーザー（聴覚障害当事者、ご家族、支援者など）

## 3. コア機能と要件
1. **情報表示**: カテゴリーや都道府県ごとに検索できるマップとリスト表示。
2. **自動監視 (定期)**: 登録されている施設のウェブサイトURLのリンク切れや更新状況を自動チェック。
3. **自動収集 (将来)**: スクレイピングによる新しい施設の自動情報収集。

## 4. 技術スタック (提案)
- **フロントエンド**: React (Vite) + プレーンCSS (モダンで美しいUIを構築)
- **マップ連携**: Google Maps API 
- **データ管理**: JSON形式 (フロントエンドのリポジトリ内で静的に管理)
- **自動化・ホスティング**: GitHub (ソースコード管理) + GitHub Actions (リンク切れ自動チェックの定期実行) + Vercel または GitHub Pages (ウェブサイトの無料公開)

## 5. 最小構成 (MVP) の範囲
まずは「動く体験」を最速で提供するため、以下の範囲を最初のゴール（MVP）と定めます。

1. **初期データの組み込みとマップ表示**: 
   すでにお持ちのリストをデータ化し、Google Maps APIを用いて地図上にピンを配置するシンプルなウェブサイトを構築します。
2. **基本的な絞り込み機能**: 
   都道府県やカテゴリーで表示を切り替えられるようにします。
3. **ローカルでのリンク切れチェックスクリプト**: 
   まずはご自身のパソコン上で実行できる、リンク切れ確認プログラムを作成します。

※ GitHubアカウントの作成、GitHub Actionsによる完全自動化、およびスクレイピングによる新規開拓は、MVP完成後の次のステップとして段階的に実装します。
